# La Canasta: logo files and brand basics

La Canasta is a daily inflation index for Argentina, built from supermarket prices.
These are the final, approved logo files (retro colour palette, on a white background). Use them as they are: do not redraw, recolour or stretch them.

## Files

| File | Use it for |
|---|---|
| `la-canasta-logo-horizontal.svg` | Website header / navbar (on white or light backgrounds) |
| `la-canasta-logo-horizontal-white.svg` | Website footer or any dark (navy) background |
| `la-canasta-logo-stacked.svg` | Hero section, reports, PDFs, title slides |
| `la-canasta-icon.svg` | Favicon (modern browsers), social profile picture |
| `la-canasta-icon-32.png` | Favicon fallback (`<link rel="icon" sizes="32x32">`) |
| `la-canasta-icon-180.png` | Apple touch icon (`<link rel="apple-touch-icon">`) |
| `la-canasta-icon-512.png` | Social media, web app manifest |
| `*.png` (logos) | Documents and slides; transparent background |

All SVGs have the text converted to shapes, so no font is needed to display them.

## Colours

| Name | Hex | Where |
|---|---|---|
| Retro navy | `#2B3B5C` | Basket, bars, wordmark, main text, headings, dark backgrounds |
| Retro celeste | `#7FB1C6` | Flag on the basket; accent colour (links, chart lines, highlights) |
| Retro sun (burnt mustard) | `#D98A2B` | The sun on the basket flag; use sparingly (one highlight, never for text on white) |
| White | `#FFFFFF` | Background, middle stripe of the flag |

## Typography

- The wordmark is set in **DM Serif Display** (Regular), free on Google Fonts.
- Website headings: DM Serif Display (Regular only, it has one weight).
- Body text, numbers, tables and charts: **DM Sans** (400 for text, 600 to 700 for labels). Same family, so they match.

## Rules

- Keep clear space around the logo of at least the height of the basket's rim bar.
- Minimum size: horizontal logo 140 px wide; icon 16 px.
- Never put the navy logo on a dark background; use the white version.
- Sky blue text on white is too faint to read: use navy for text.
